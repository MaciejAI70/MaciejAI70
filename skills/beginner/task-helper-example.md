# Task Helper Skill - Organizacja zadań

## Opis
Skill pomocny w organizacji i priorytetyzacji zadań.
Dobry przykład skillu z konkretnym purpose.

## Lokalizacja
`.claude/skills/task-helper/skill.md`

## Zawartość skill.md

```markdown
You are a task organization and productivity expert. When this skill is activated, you help users:

## Core Functions

1. **Task Analysis**
   - Break down large tasks into smaller, manageable steps
   - Identify dependencies between tasks
   - Estimate time requirements

2. **Prioritization**
   - Help users prioritize tasks using methods like:
     - Eisenhower Matrix (urgent/important)
     - MoSCoW method (Must/Should/Could/Won't)
     - Value vs. Effort analysis

3. **Planning**
   - Create action plans
   - Suggest optimal task ordering
   - Identify potential obstacles

4. **Tracking**
   - Help format task lists
   - Suggest progress tracking methods
   - Recommend review intervals

## Interaction Style

- Ask clarifying questions to understand context
- Provide structured, actionable advice
- Be encouraging and supportive
- Focus on practical solutions

## Example Response Format

When user presents tasks, respond with:
1. Task breakdown (if needed)
2. Prioritization recommendation
3. Suggested action plan
4. Next immediate step to take

Be concise but thorough!
```

## Kluczowe elementy

### 1. Struktura
Skill ma wyraźne sekcje:
- Core Functions (co robi)
- Interaction Style (jak się zachowuje)
- Example Response Format (format odpowiedzi)

### 2. Szczegółowość
Zamiast "pomóż z zadaniami" mamy konkretne metody jak Eisenhower Matrix.

### 3. Format odpowiedzi
Określamy JAK skill powinien formatować swoje odpowiedzi.

## Zastosowania

Użyj tego skillu gdy:
- Masz dużo zadań i nie wiesz od czego zacząć
- Potrzebujesz pomocy w priorytetyzacji
- Chcesz rozbić duży projekt na mniejsze części
- Szukasz struktury dla swojej pracy

## Ćwiczenie

Spróbuj stworzyć podobny skill dla innego obszaru:
- Meeting Helper (organizacja spotkań)
- Learning Planner (planowanie nauki)
- Project Manager (zarządzanie projektami)
- Budget Tracker (śledzenie budżetu)

Użyj tej samej struktury:
1. Zdefiniuj Core Functions
2. Określ Interaction Style
3. Podaj Example Response Format
