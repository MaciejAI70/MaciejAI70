# Quick Start Guide

Chcesz szybko zacząć? Ten przewodnik przeprowadzi Cię w 5 minut!

## Krok 1: Uruchom instruktora (1 min)

```bash
python3 skills-instructor.py
```

To uruchomi interaktywnego nauczyciela, który poprowadzi Cię krok po kroku.

## Krok 2: Przejdź Lekcję 1 (3 min)

W menu wybierz:
```
1. 🎓 Lekcja 1: Czym są Skills?
```

Dowiesz się:
- Co to są skills
- Jak działają
- Do czego służą

## Krok 3: Stwórz pierwszy skill (5-10 min)

W menu wybierz:
```
2. 🛠️ Lekcja 2: Stwórz swój pierwszy Skill
```

Instruktor pomoże Ci stworzyć działający skill!

## Krok 4: Testuj! (2 min)

Po stworzeniu skillu, przetestuj go:

```bash
# W katalogu projektu
claude
```

Następnie w Claude Code:
```
/nazwa-twojego-skillu
```

## Gotowe przykłady do nauki

### Proste przykłady (dla początkujących):
- `skills/beginner/hello-skill-example.md`
- `skills/beginner/task-helper-example.md`

### Zaawansowane przykłady:
- `skills/advanced/code-reviewer-example.md`

### Szablony do użycia:
- `templates/skill-template-basic.md` - dla prostych skills
- `templates/skill-template-advanced.md` - dla zaawansowanych
