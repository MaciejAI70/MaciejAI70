# Skills Instructor - Twój Przewodnik po Claude Code Skills

Witaj w interaktywnym kursie tworzenia i instalacji skills w Claude Code!

## Czym jest ten projekt?

To kompleksowy system nauczania, który krok po kroku przeprowadzi Cię przez:
- Zrozumienie czym są skills w Claude Code
- Tworzenie własnych skills od podstaw
- Instalację i testowanie skills
- Zaawansowane techniki i best practices

## Szybki Start

Uruchom interaktywnego instruktora:

```bash
python3 skills-instructor.py
```

## Struktura Projektu

```
MaciejAI70/
├── skills-instructor.py       # Główny interaktywny instruktor
├── skills/                    # Przykładowe skills do nauki
│   ├── beginner/              # Skills dla początkujących
│   └── advanced/              # Zaawansowane przykłady
├── lessons/                   # Materiały szkoleniowe
├── templates/                 # Szablony do tworzenia skills
└── .claude/                   # Katalog Claude Code (utworzysz go w trakcie)
```

## Co się nauczysz?

1. **Podstawy Skills** - czym są i jak działają
2. **Twój pierwszy skill** - stworzenie prostego "Hello World" skill
3. **Kalkulator** - skill z parametrami i logiką
4. **Web Fetch** - zaawansowany skill z zewnętrznymi API
5. **Best Practices** - jak pisać czyste i użyteczne skills

## Wymagania

- Python 3.6+
- Claude Code CLI zainstalowany
- Podstawowa znajomość terminala

## Wsparcie

Jeśli masz pytania podczas nauki, instruktor posiada wbudowany system pomocy.
Użyj opcji "Help" w menu głównym.
