# 🚀 JAK ZACZĄĆ - Szybki Start

## Instalacja (wybierz jeden sposób):

### Sposób 1: Użyj instruktora (NAJŁATWIEJSZY)
```bash
python3 skills-instructor.py
# Wybierz opcję 5
# Powiedz "t" (tak) dla obu nauczycieli
```

### Sposób 2: Użyj gotowego skryptu
```bash
./install-language-teachers.sh
```

### Sposób 3: Ręcznie
```bash
mkdir -p .claude/skills/spanish-teacher-a2
mkdir -p .claude/skills/english-teacher-a2
# Skopiuj zawartość z skills/languages/spanish-teacher-a2.md
# do .claude/skills/spanish-teacher-a2/skill.md
# (analogicznie dla angielskiego)
```

---

4. **Rozpocząć konwersację** na dowolny temat z poziomu A2
