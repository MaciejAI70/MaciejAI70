# Hello Skill - Przykład dla początkujących

## Opis
To jest najprostszy możliwy skill dla Claude Code.
Pokazuje podstawową strukturę i sposób działania.

## Lokalizacja
Ten plik powinien być w: `.claude/skills/hello-skill/skill.md`

## Zawartość skill.md

```markdown
You are a friendly greeting expert. When this skill is activated, you will:

1. Greet the user warmly
2. Ask them how they are doing
3. Provide an interesting fact or motivational quote
4. Wish them a great day

Be enthusiastic and friendly in your responses!
```

## Jak użyć

1. Skopiuj powyższą zawartość do `.claude/skills/hello-skill/skill.md`
2. W Claude Code wpisz: `/hello-skill`
3. Ciesz się działającym skillem!

## Czego się nauczysz

- Jak stworzyć podstawowy plik skill.md
- Jak strukturyzować instrukcje dla Claude'a
- Jak uruchomić skill w Claude Code
- Podstawy pisania promptów dla skills

## Modyfikacje do wypróbowania

Spróbuj zmienić skill, aby:
- Witał w różnych językach
- Dawał różne rodzaje cytatów (motywacyjne, zabawne, mądre)
- Pytał o konkretne rzeczy (plany na dzień, nastrój)
- Reagował na porę dnia (dzień dobry, dobry wieczór)

## Wskazówki

✅ DO:
- Pisz jasne, konkretne instrukcje
- Używaj list numerowanych dla kroków
- Podawaj przykłady zachowań

❌ DON'T:
- Nie pisz zbyt ogólnych instrukcji
- Nie używaj skomplikowanego języka
- Nie zakładaj, że Claude wie co masz na myśli
